## 📈 Learning Outcomes

Through these projects, I focus on mastering the following key skills:
1.  **Data Preprocessing:** Cleaning data, handling missing values, and Feature Scaling.
2.  **Model Selection:** Choosing the right algorithm for the task (Regression vs. Classification).
3.  **Model Evaluation:** Interpreting Confusion Matrices and calculating Precision, Recall, and F1-Score.
4.  **Hyperparameter Tuning:** Optimizing model performance (e.g., finding the best 'K' in KNN).
